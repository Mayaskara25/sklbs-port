# The Fresh Five

A retro diner group portfolio with a dimensional polished-chrome counter, reflective glass juice tanks, metallic tap handles, and a checkerboard floor. Five interactive juice dispensers for Krishna, Karthik, Mayaskara, Litheesh, and Kushal.

## Run locally

From this directory:

```sh
npm run dev
```

Open http://localhost:3000. No installation or build step is needed. Stop the server with Ctrl+C.

You can also open `index.html` directly in a browser. Google Fonts are optional; local font fallbacks are provided.

## Experience

Click or drag a lever downward, or select “Pull to meet.” Juice fills the cup, expands to cover the screen, and reveals that person's matching portfolio. Use “Back to the juice bar,” the logo, or your browser history to return. Each portfolio also links to the next person's blend. Direct links use name fragments, for example `#krishna`.

Names, flavours, colors, and introductory lines are in the `people` array in `app.js`. Portfolio content is generated by `renderPortfolio`. Skills, education, experience, contact, and projects are explicitly marked placeholders pending real resume content.

The page supports narrow screens, keyboard activation, focus indicators, and reduced-motion preferences. Nothing has been deployed.

## Cinematic backdrop

The scene uses `assets/diner-cinematic.jpg`, generated with the built-in image generation tool and optimized as a local JPEG. Its generation prompt is saved in `assets/diner-background-prompt.txt`. The photographic room remains visible behind both the working counter and portfolio menus. Responsive crops, warm chrome highlights, neon title lighting, and a vignette connect the foreground with the backdrop.
