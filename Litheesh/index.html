LT-01 · AUDIO / EMBEDDED In development · Course lab project

Emergency vehicle siren detection with phase-aware signal preemption

A system that hears an approaching ambulance, works out which direction it's coming from, and changes the traffic signal with as little disruption as possible.

  • Two-stage design: an ESP32 with MEMS microphones screens audio on the device, and a convolutional neural network on a Flask server confirms the siren.
  • Finds direction from the tiny difference in when the sound reaches each microphone, using a cross-correlation method called GCC-PHAT.
  • The signal-change logic covers four traffic-light phase scenarios, so it only intervenes as much as needed.
  • Trained on a siren dataset I recorded myself on Bengaluru roads.

LT-02 · ML RESEARCH Experiments complete, paper drafted · Team of 4, college project

EmbedEd: does the choice of training negatives matter?

When you fine-tune a model to tell similar things apart, you train it on pairs that should match and “negatives” that shouldn't. We tested whether picking harder negatives makes a code-understanding model better at spotting duplicate code.

  • Fine-tuned GraphCodeBERT on the BigCloneBench duplicate-code dataset under seven conditions: random, keyword-matched (BM25) and meaning-matched negatives, each with and without a filter, plus an untrained baseline.
  • Result: random negatives scored best, with an F1 score (a combined accuracy measure from 0 to 1) of 0.75, against 0.26 for the untrained model. The “smarter” hard negatives were no better than the baseline.
  • Traced the failure to hard negatives that were actually duplicates themselves, plus a loss margin too small for the model's narrow similarity range. Filtering helped (0.42 to 0.47), but still didn't beat random.
  • Tested generalisation on code tasks the model had never seen, with F1 between about 0.67 and 0.72.
  • Written up as a five-page IEEE-format paper, plus a demo page comparing all seven models.

LT-05 · GRAPHS / BIO-INSPIRED In progress · Team of 4, Bioinspired Engineering course

Self-healing routing on Bengaluru's road network

How quickly can a routing algorithm recover when a road suddenly closes? We compare nature-inspired methods against classical shortest-path search on real city data.

  • Ant colony optimisation and slime-mould (Physarum) network growth versus Dijkstra and A* search.
  • Real Bengaluru road network from OpenStreetMap, with traffic simulated in SUMO.
  • One shared benchmark measuring recovery after road and junction failures.
