# N Litheesh — Portfolio

A single-page portfolio in plain HTML, CSS and JavaScript (no frameworks, no build step), styled like a lab instrument.

Open `index.html` in a browser, or serve the folder with any static host (e.g. GitHub Pages).

## Interactive pieces
- **Hero mic array** (`js/hero.js`): four microphones estimate a sound source's bearing from time-difference-of-arrival. The pointer is the source.
- **Road rerouting** (`js/demos.js`): click a road to close it and Dijkstra recomputes the route.
- **Blob hasher** (`js/demos.js`): computes the same SHA-1 address as `git hash-object`.

Respects `prefers-reduced-motion` and has a light/dark switch.
